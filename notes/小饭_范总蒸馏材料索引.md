## 推荐阅读顺序

1. 先读 `小饭_范总人物方法论蒸馏_v1.md`，建立整体画像。
2. 再读 `小饭_范总时间线.md`，理解这个人为什么会形成这套判断系统。
3. 然后读 `小饭_范总判断模型卡片.md`，把他的判断方式拆成可迁移工具。
4. 最后读 `小饭_范总表达风格词典.md`，理解他为什么能把冷判断讲得有节目效果。

## 后续新素材归档方式

新增直播或视频文字稿时，先判断素材主要补充哪一类：

| 新素材内容 | 应归档到 |
|---|---|
| 北京经历、过去人物、人生转折 | `小饭_范总时间线.md` |
| 宏观、政策、市场、交易方法 | `小饭_范总判断模型卡片.md` |
| 经典句式、梗、直播效果、叙事技巧 | `小饭_范总表达风格词典.md` |
| 足以改变人物画像的新证据 | `小饭_范总人物方法论蒸馏_v1.md` |

## 每次处理新素材的标准流程

```text
1. 摘要：这份素材讲了什么。
2. 分类：经历线 / 判断模型 / 表达风格 / 反例修正。
3. 提取：新观点、新故事、新句式、新证据。
4. 对照：它支持、补充还是修正现有结论。
5. 更新：写入对应文件，并保留来源文件名。
```

## 当前最值得继续补的材料

- 更多近期舰长/直播内容：补交易观、风险边界和节目效果。
- 更多北京故事系列：补经历线和人物关系。
- 更多宏观视频：验证他的“利益结构优先”是否稳定。
- 更多失败复盘内容：补“失败训练”和“周期验证”模型。

## 当前结论

现在这套材料已经不是单篇总结，而是一个小型人物分析库。后面每加入一份新字幕，都应该变成“证据增量”，而不是重新写一遍人物印象。

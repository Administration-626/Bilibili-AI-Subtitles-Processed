## 1. Recurring Ideas (高频核心观点)

- **A股的本质是承接流动性的“合法赌场”与零和博弈**
  - *Evidence [Source 1, Line 570-616]*: 当其他高回报渠道对普通人关闭时，股市成了唯一合法赌场。股市就是剪羊毛的地方。
  - *Evidence [Source 2, Line 108-145, 726-727]*: “量化”交易（Quantitative Trading）的入场彻底改变了股市生态，技术图形（如K线、均线）随时会被量化机构伪造（“量化会做假图形”）以收割散户。
- **疫情只是经济调整的背锅侠/催化剂**
  - *Evidence [Source 1, Line 11-30]*: 疫情并不是主要因素，它只是被用来吸食泡沫和掩盖结构性问题的借口。
- **大类资产（房/车）的熄火掩盖了通胀**
  - *Evidence [Source 1, Line 274-324]*: 真正的大头消费是房子和车子。普通人不再碰大头消费，导致整体呈现“通缩假象”和全面保守化（“躺了”）。

## 2. Decision Rules (行为与判断准则)

- **股市投资的“技术面失效”法则**
  - *Rule*: **IF** 一只股票走出了完美的经典技术突破图形（如“突破箱体主升浪”），**THEN** 极大概率是量化资金做的“假图形”骗局，坚决不追高。
  - *Evidence [Source 2, Line 631-680, 758-782]*: 面对标准放量突破图形，小饭的判断是：“你信不了一点，进去马上就给我表演一手跳水。”
- **宏观趋势/龙头战法法则（逻辑型交易）**
  - *Rule*: **IF** 目标是稳健的30%收益，**THEN** 放弃小盘股，只买宏观大势（如地缘政治、黄金/铜周期）驱动的行业龙头。技术面只作为进场辅助，不作为买入理由。
  - *Evidence [Source 2, Line 730-738, 787-794]*: “我基本不买小盘股，就买龙头。我已经看好它的长期趋势了……地缘的趋势、美元的趋势。技术面只是保底，完全不是购买决策。”
- **关于买房的判定**
  - *Rule*: **IF** 并非结婚绝对强制要求，**THEN** 坚决不买房。
  - *Evidence [Source 1, Line 736-764]*: “房子绝对不是真正的刚需。”

## 3. Mental Models (底层心智模型)

- **万物皆 K 线（周期与轨迹模型）**
  - *Model*: 股票 K 线不仅是金融指标，它暗含着“返璞归真的大道理”。个人的睡眠节律、体重波动，甚至宏观大势的起伏，都可以被抽象为带着支撑位与阻力位的 K 线图。
  - *Evidence [Source 2, Line 616-627, 688-698]*: “万事万物皆K线……一个人的每天的入睡时间其实也是一个K线图，完全可以进行技术分析，蕴藏着大道理。”
- **“大国博弈下的代价模型”**
  - *Model*: 面对美联储加息的收割，中国选择“硬挺/硬刚”。代价是外向型经济受损，普通人的就业和收入必然承受巨大压力。
  - *Evidence [Source 1, Line 125-162]*: “我们就是迎难而上……就是要对攻。”
- **投资者的“消费克制螺旋”**
  - *Model*: 进入股市后，无论盈亏，个人的物理消费都会断崖式下跌。亏钱了，要把钱留着补仓；赚钱了，会觉得1块钱在股市里能变成2块钱，更舍不得花。
  - *Evidence [Source 2, Line 205-219, 264-271]*: “亏了赚了其实都不影响你的消费，就直线下跌……清心寡欲。”

## 4. Vocabulary (专属词汇与话语标记)

- **盘感**：被认为是通过无数次亏损和复盘后建立的动物本能与直觉，超越了表面的技术分析。
- **量化**：散户的天敌，没有感情的虚假图形制造机。
- **逻辑型股神 / 趋势型股神**：小饭对自己的定位，即通过推演世界宏观基本盘来做决策的交易者。
- **收割 / 剥夺剩余价值**：描述金融资本对普通人的财富转移机制。

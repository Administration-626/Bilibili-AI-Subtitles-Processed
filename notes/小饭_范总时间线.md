# 小饭/饭总时间线

## 使用说明

这份时间线不是严格传记，而是根据当前素材整理出的“人物变化轨迹”。素材中存在化名、小说化讲述、节目效果和口误，所以这里更适合用于分析人物方法论，而不是核验现实身份。

核心问题：

> 小饭/饭总是怎么从北京金融圈里的工具人，变成一个擅长讲利益结构、市场博弈、失败周期和交易盘感的人？

---

## 阶段一：入京与被驯化

### 关键词

工具人、名片、背锅、低姿态、锐气被磨平。

### 主要事件

- 小范毕业后来到北京，进入一家亚洲知名的金融机构。
- 公司里研究生、博士很多，他一开始并没有天然优势。
- 他从跑腿、复印、做 PPT、写商业计划书、开车、记会议纪要开始，被放在标准工具人位置。
- 他逐渐学会低姿态生存：主动请教、送小礼、背锅、哄前辈开心。
- 老前辈酒后告诉他，金融最重要的是“狠心”，除了自己以外其他人都是工具人。

### 人物变化

这一阶段的小范完成了第一次降维：从“相信个人能力”转向“接受组织位置”。他意识到，能力不是单独生效的，能力必须挂靠在名片、前辈、公司和关系链上。

### 方法论沉淀

```text
先活下来，再谈发挥。
先识别自己在别人系统里的用途，再寻找反向利用系统的机会。
```

---

## 阶段二：P2P、包装与金融故事

### 关键词

虚假项目、包装、非法融资、平台背书、故事变现。

### 主要事件

- 老前辈参与 X 公司相关项目，背后是线下理财转线上 P2P。
- 小范经手项目报告时发现大量离谱项目，比如变色雨衣、飞翔鞋。
- 老蒋用高收益率吸引用户，把项目包装成理财、股权、众筹的混合故事。
- 口碑危机出现后，团队通过广告、媒体专访、慈善秀来修复公众信任。
- 小范看见老蒋的表演能力，如果不知道内幕，甚至会被其真情实感打动。

### 人物变化

这一阶段他开始理解：金融世界里“故事”本身就是资产的一部分。真相不一定先于信任，很多时候是信任先被包装出来，然后再拿信任换钱。

### 方法论沉淀

```text
不要只问项目真不真。
要问：这个故事服务谁？谁负责讲？谁负责背书？钱进入后如何流转？
```

---

## 阶段三：星星会与顶层游戏

### 关键词

圈层、信息交换、慈善包装、股权套现、资源巩固。

### 主要事件

- 老蒋进入北京顶级企业家圈层“星星会”。
- 星星会表面是慈善拍卖，实际承担信息交换、关系巩固、资源分配功能。
- 徐冲浪借慈善拍卖包装股权流动性问题，老蒋拍下后转手放到 P2P 平台融资。
- 短时间内，平台借助“互联网大咖项目”叙事集资数亿。
- 老前辈通过中间人角色赚到大量手续费，也给小范分到额外奖金。

### 人物变化

小范看见了更高层级的玩法：资产不只是资产，资产也可以被包装成门票、话题、信任符号和融资工具。越往上走，规则越不写在明面上。

### 方法论沉淀

```text
顶层局不是单纯交易，而是信息、身份、信用、通道和退出路径的交换。
```

---

## 阶段四：分裂选择与留守上位

### 关键词

撇清风险、工资翻倍、公司名片、切割、利益下的感情。

### 主要事件

- 老鲁判断 X 公司风险不可控，要求团队与老蒋撇清关系。
- 老怪和老前辈因赚得太多，选择离开公司跟老蒋干。
- 老蒋通过酒局、红包、工资翻倍、职位承诺，煽动年轻人一起出走。
- 酒醒后，老前辈劝小范留下，核心理由是公司名片比眼前的钱更重要。
- 老前辈说，在这个行当没有永久情谊，只有利益；不伤害利益时才能讲感情。
- 小范最终留下，并在原团队撤走后获得上位机会。

### 人物变化

这是小范真正学会“切割”的阶段。他第一次把“工具人”哲学变成自己的行动策略：不跟着情绪走，不跟着短期钱走，而是选择更有长期杠杆的位置。

### 方法论沉淀

```text
短期收益不等于长期筹码。
当所有人被钱和情绪推着走时，反而要看谁的名片、位置和退路更硬。
```

---

## 阶段五：崛起与信息差变现

### 关键词

互联网刁民、小项目、大佬看不上、信息不对称、搞钱搭档。

### 主要事件

- 团队出走后，小范接住一批没人处理的项目。
- 他通过内部考核、资格证，正式顶上位置。
- 老前辈曾随手打发给他的 A、B 等小互联网创业者，后来反而成为他的关键机会。
- A 的生鲜电商项目和 B 的隐秘项目，奠定了他在公司的地位。
- 小范与小 C 形成微妙合作关系，既合作又互坑，目标一致：搞钱。
- 小 C 通过社交局、牌局、信息调查接近项目方，小范通过公司通道和信息优势处理投资。

### 人物变化

这一阶段的小范从“被别人使用的工具人”变成“会使用系统和信息差的人”。他开始有自己的项目、关系、判断和分成能力。

### 方法论沉淀

```text
大佬看不上的边角料，可能是新人最好的上升通道。
信息差不是道德问题，而是利益分配问题。
```

---

## 阶段六：恐惧、告密与退意

### 关键词

夜光宝石、庞氏尾声、星星会冲击、太烫了、告密。

### 主要事件

- 老前辈出走后资源断裂，又找小范帮老蒋穿针引线。
- 小范看到“夜光宝石”项目，判断从头到尾都是编的，说明老蒋后期已经进入庞氏尾声。
- 老前辈带他参加星星会拍卖，规模、排场和资金量让他产生强烈恐惧。
- 他意识到水太深、量级太大，自己驾驭不了。
- 回去后，他向老鲁报告老前辈回来挖资源。
- 老前辈痛骂他不地道，小范用“前辈不是告诉我所有人都是工具人吗”回应。

### 人物变化

这是小范从“学会规则”到“意识到规则会吞人”的阶段。他不是道德突然觉醒，而是判断风险超过自身承载能力，于是选择切割。

### 方法论沉淀

```text
看懂局不等于能入局。
真正危险的不是项目假，而是局的量级超过你的承受能力。
```

---

## 阶段七：黑金时代与被时代吞没

### 关键词

J、沪金宝、银行通道、燕郊、体量、股市狂飙、失败。

### 主要事件

- J 做小贷和“信用超市”，希望通过假理财项目吸收资金，把体量做大。
- 小范提醒其违法和坏账风险，但 J 真正目标是用体量换银行高管的项目通道。
- J 勾结银行高管，把银行推掉的优质项目接过来，既放贷又入股。
- 假项目逐步被真实资产填实，并借燕郊房地产红利赚到大钱。
- 小范借 J 的资源包装自己，拿下 H 的项目并赚到一笔。
- 这次成功改变了他的心态，让他觉得辛勤劳动的钱不值一提。
- 2015 年他进入股市，开始自认为的人生狂飙，最后大败。
- 2015-2018 年在北京摆烂，2018 年底离开，2019 年回老家创业，2020 年创业失败。

### 人物变化

这是他的命运转折：他看懂了时代红利和黑金玩法，但没有像 J 那样拿到足够多筹码，也没有足够早离场。于是他从观察者变成被浪潮吞没的人。

### 方法论沉淀

```text
成功是短暂窗口。
区别不在于谁不失败，而在于谁在高光期拿到了足够多筹码，能不能扛住后面的下行。
```

---

## 阶段八：离京后的轻松与自我修复

### 关键词

相对失败、轻松、游戏、现实懦弱、充钱变强。

### 主要事件

- 小范离开北京后，人生从短暂辉煌变成相对失败。
- 但他反而感到轻松、开心。
- 他回归大学时期的游戏状态，展示大量手游消费。
- 这部分常以自嘲、二次元、游戏梗方式表达。

### 人物变化

离京后的他不再完全追求金融圈式胜利。这里有一种失败后的放松：不再被高强度利益关系追着跑，也不再必须时时刻刻扮演强者。

### 方法论沉淀

```text
离开高筹码系统，不一定是成功，但可能是自我恢复。
人不只需要赢，也需要从必须赢的环境里逃出来。
```

## 阶段九：近期直播中的交易化表达

### 关键词

股神、天才交易员、盘感、左侧、错价、仓位、情绪价值、风险边界。

### 主要事件

- 在近期直播中，他大量讨论 A 股、美股、AI、芯片、存储、油气、金银、周期股等。
- 他说市场最终是对的，但市场存在错误定价时期。
- 他强调交易者要知道自己的资金周期、目的和忍耐时间。
- 他相信盘感，但把盘感解释成长期操作形成的模式库。
- 他区分 A 股和美股：A 股更依赖政策、情绪、量价、人性博弈，美股更偏基本面、趋势和全球科技叙事。
- 他调侃“股神”“天才交易员”“拿麻袋装钱”，但也多次强调股票内容是解压和节目效果，不是投资建议。

### 人物变化

北京时期的利益结构经验，迁移成了交易语言：

- 过去看人和项目，现在看资金和市场。
- 过去看名片和通道，现在看政策和量化。
- 过去看谁能离场，现在看谁能穿越周期。
- 过去讲“工具人”，现在讲“市场参与者不是铁板一块”。

### 方法论沉淀

```text
交易不是预测涨跌，而是在不同参与者、不同周期、不同情绪压力之间找错位。
```

---

## 总结：人物变化主线

```text
外地新人
-> 金融工具人
-> 包装和项目观察者
-> 利益结构学习者
-> 信息差使用者
-> 黑金时代参与者
-> 股市和创业失败者
-> 离京后的自嘲叙事者
-> 近期交易/宏观观察者
```

最重要的变化不是“他变得更会赚钱”，而是：

> 他把北京金融圈的残酷经验，转译成了一套分析世界的语言：利益、筹码、规则、周期、失败、情绪和退出路径。

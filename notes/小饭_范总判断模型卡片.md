# 小饭/范总判断模型卡片

## 使用说明

这份文件把 `小饭_范总人物方法论蒸馏_v1.md` 中的判断方式拆成卡片。以后新增直播、视频、故事素材时，可以按卡片归类：

- 这段是在讲利益结构？
- 是在讲筹码？
- 是在讲市场错价？
- 是在讲盘感？
- 是在讲周期和失败？
- 还是在讲表达边界和节目效果？

---

## 卡片 1：利益结构优先

### 一句话

任何现象背后，先看利益分配，而不是先看表面解释。

### 核心问题

- 谁从这件事里获利？
- 谁承担代价？
- 谁有能力改变规则？
- 谁必须被安抚？
- 谁只是被叙事动员进来的？

### 常见触发场景

- 宏观政策
- 房地产
- 金融监管
- 平台经济
- 股市行情
- 企业融资
- 舆论公关

### 典型表达

```text
政策不是最优解，而是利益集团博弈的结果。
市场不是完全自由的，是制度塑造出来的。
```

### 使用方法

看到一个新闻或观点时，不要先判断真假，先画利益图：

```text
政策/事件
-> 受益方
-> 受损方
-> 中间方
-> 被安抚方
-> 被转嫁方
```

### 注意事项

这个模型容易让人过度犬儒。不是所有事情都只有利益，但在金融、政策和市场场景里，利益结构通常是最硬的解释层。

---

## 卡片 2：规则制定者

### 一句话

真正重要的不是玩家怎么下注，而是谁在制定牌桌规则。

### 核心问题

- 规则是谁定的？
- 规则会向谁倾斜？
- 谁能提前知道规则变化？
- 谁能绕开规则？
- 谁只能被规则处理？

### 常见触发场景

- 金融牌照
- 银行信贷
- 地方财政
- 房地产限购
- 股市政策预期
- 行业监管

### 典型表达

```text
投资不只是研究公司和行业，更重要的是理解谁在制定规则、谁在分配利益。
```

### 使用方法

当一个行业突然变化时，按顺序查：

1. 规则是否变了。
2. 规则变化保护谁。
3. 规则变化打击谁。
4. 哪类玩家提前布局。
5. 普通参与者是否只能接最后反馈。

### 注意事项

不要把“规则制定者”神秘化。很多时候规则不是某个人的单点意志，而是多个压力共同挤出来的结果。

## 卡片 3：筹码思维

### 一句话

人生和交易的关键不是一时判断对错，而是你手里有什么筹码，能不能撑到结果兑现。

### 核心问题

- 我现在的筹码是什么？
- 这个筹码能换来什么？
- 这个筹码会不会过期？
- 我有没有退路？
- 我是在积累筹码，还是消耗筹码？

### 筹码类型

- 公司名片
- 现金
- 信息差
- 人脉
- 项目入口
- 交易仓位
- 时间
- 情绪稳定性
- 能离场的自由

### 典型表达

```text
你现在最重要的不是钱，而是这家公司的名片。
高光期要搞到足够多筹码，才能应对后面的落落落。
```

### 使用方法

做选择时不要只比收益，要比筹码变化：

```text
选择 A：短期钱更多，但失去名片/退路。
选择 B：短期钱少，但保留平台/身份/长期机会。
```

### 注意事项

筹码思维很冷，也很容易把所有关系工具化。用于决策可以，用于生活要留余地。

---

## 卡片 4：包装与现金流

### 一句话

漂亮故事的背后，要拆现金流、背书链和退出路径。

### 核心问题

- 钱从哪里来？
- 以什么名义进来？
- 谁负责讲故事？
- 谁提供背书？
- 钱真正流向哪里？
- 谁能提前拿钱离场？
- 最后一棒是谁？

### 常见包装

- 理财产品
- 众筹项目
- 慈善拍卖
- 互联网大咖项目
- 国外科技
- 公益人设
- “人人当股东”
- 高收益低风险

### 典型表达

```text
把故事包装好，让其他人来投就行了。
假的项目通过真实资产反向填实。
```

### 使用方法

遇到项目时做三步拆解：

1. 拆故事：它在让你相信什么？
2. 拆现金流：钱进来后经过谁？
3. 拆退出：谁有确定退出，谁只能等结果？

### 注意事项

并非所有包装都是骗局。问题在于包装是否掩盖了真实风险、真实现金流和真实责任人。

## 卡片 5：错价与市场反馈

### 一句话

市场最终会给结果，但短期存在错误定价、情绪错杀和过度追捧。

### 核心问题

- 当前价格是由什么力量推出来的？
- 是基本面、政策、情绪、资金压力，还是被动交易？
- 如果我认为市场错了，我能等多久？
- 我的资金周期和市场纠错周期匹配吗？
- 我是在找错价，还是在给亏损找借口？

### 典型表达

```text
市场最终是对的。
不用纠结市场对不对，要洞悉规律，在它错的时候根据波动做选择。
```

### 使用方法

判断错价时同时写下：

```text
我的假设：
市场当前定价：
我认为错在哪里：
需要多久验证：
如果三个月/半年不兑现，我怎么处理：
```

### 注意事项

“市场错了”是最危险的自我安慰之一。必须配退出条件，否则很容易变成被套后的价值叙事。

## 卡片 6：盘感训练

### 一句话

盘感不是天降直觉，而是长期在量价、情绪、政策和失败里训练出的模式识别。

### 核心问题

- 我见过多少类似结构？
- 这次像过去哪个模板？
- 这次和过去模板哪里不同？
- 我的盘感来自成功样本，还是亏损阴影？
- 我有没有用结果校正盘感？

### 盘感来源

- 技术指标
- K 线和量价
- 情绪面
- 政策面
- 人性博弈
- 成功记忆
- 失败记忆
- 长期盯盘形成的肌肉记忆

### 典型表达

```text
盘感是在大脑里训练出来的。
每一次操作失败和成功都会留下印象。
这是真正的神经网络。
```

### 使用方法

每次交易后记录：

```text
当时看到的形态：
当时的情绪：
买入/卖出理由：
结果：
这次样本以后归入哪个模板：
```

### 注意事项

没有样本量的盘感通常只是冲动。盘感必须被复盘和结果校正，否则会变成玄学。

## 卡片 7：左侧交易与等待

### 一句话

左侧交易赚的是市场尚未承认你之前的错位，但代价是等待、回撤和自我怀疑。

### 核心问题

- 我买的是反转，还是下跌中继？
- 我能承受多久不涨？
- 我有补仓计划吗？
- 我有没有仓位纪律？
- 哪个信号说明我错了？

### 典型场景

- 情绪错杀
- 周期底部
- 市场过度悲观
- 资金短期被动卖出
- 基本面未坏但价格先崩

### 典型表达

```text
机会可能是被短期情绪错杀的票子。
左侧交易吃亏损等反转。
```

### 使用方法

左侧前先写：

```text
底层逻辑：
最大回撤：
等待时间：
加仓条件：
止损/认错条件：
```

### 注意事项

左侧交易最怕没有仓位管理。判断对但仓位错，也会先被市场打穿。

## 卡片 8：周期验证

### 一句话

一轮行情里赚钱不算本事，穿越周期后还能赚钱才算模型成立。

### 核心问题

- 这次赚钱是能力还是行情？
- 我的模型经历过牛市、震荡和下跌吗？
- 我是否至少穿越一个完整周期？
- 我在亏损时是否会变形？
- 我能否保持行动力？

### 典型表达

```text
稳定赚钱至少要穿越一个半周期。
如果长期在股市赚到可观收益，做什么基本都会成功。
```

### 使用方法

评估一个交易者或方法时，不看单月收益，先看：

```text
周期长度：
最大回撤：
收益来源：
仓位变化：
是否靠单一行情：
行情逆转后的表现：
```

### 注意事项

不要被短期收益迷惑。短期高收益可能只是高 beta、重仓或运气。

## 卡片 9：失败训练

### 一句话

失败不是偶发事故，而是人生和交易的常态；关键是把失败变成可用样本。

### 核心问题

- 这次失败暴露了什么？
- 是判断错、仓位错、周期错，还是心态错？
- 我有没有把一次成功误认为永久能力？
- 我有没有在高光后失去敬畏？

### 典型表达

```text
失败和遗憾贯穿人生始终。
人生不是起起落落，而是起，然后落落落。
```

### 使用方法

失败复盘四问：

1. 当时我相信什么？
2. 市场/现实给了什么反馈？
3. 我在哪里变形？
4. 下次如何让损失更小、样本更清楚？

### 注意事项

不要浪漫化失败。失败只有被复盘、归因和修正后，才是训练数据。

---

## 卡片 10：表达边界

### 一句话

公开聊金融时，要区分观点、节目效果、情绪安慰和行动建议。

### 核心问题

- 这句话是在认真分析，还是直播效果？
- 有没有具体个股或操作指令？
- 观众会不会把它当建议？
- 主播是否明确提示风险？
- 这段内容更适合总结成认知，还是交易建议？

### 典型表达

```text
股票市场很有风险。
这个本质上是调侃，更多是给大家解压用的。
```

### 使用方法

整理直播时标注四类：

```text
严肃观点：
节目效果：
风险提醒：
明确安排：
```

### 注意事项

金融内容只整理观点，不给投资建议。尤其是直播里的“股神”“拿麻袋装钱”，很多时候是节目效果。

---

## 总卡：小饭式判断流程

```text
1. 先拆现象：发生了什么？
2. 再拆利益：谁赚、谁亏、谁承担后果？
3. 再拆规则：谁制定规则，谁能绕开规则？
4. 再拆筹码：谁有名片、现金、信息、退路？
5. 再拆叙事：这个故事包装给谁听？
6. 再拆市场：价格里包含哪些情绪和资金压力？
7. 再拆周期：这个判断需要多久验证？
8. 最后拆自己：我能不能承受等待、亏损和失败？
```
